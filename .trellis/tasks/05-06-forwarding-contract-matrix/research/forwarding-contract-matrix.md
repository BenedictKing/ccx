### Central same-format decision

`passthrough.Decide` classifies inbound path format, outbound service format, strict body passthrough, raw response passthrough, and Messages-only skip-preprocess in one place (`backend-go/internal/passthrough/passthrough.go:30`). Inbound formats are:

| Inbound path family | Inbound format | Evidence |
|---|---|---|
| `/v1/messages`, `/v1/messages/count_tokens` | `claude_messages` | `backend-go/internal/passthrough/passthrough.go:49` |
| `/v1/responses` | `openai_responses` | `backend-go/internal/passthrough/passthrough.go:54` |
| `/v1/chat/completions` | `openai_chat` | `backend-go/internal/passthrough/passthrough.go:56` |
| `/v1beta/models/...:generateContent`, `/v1/models/...:streamGenerateContent` | `gemini_contents` | `backend-go/internal/passthrough/passthrough.go:65` |

Outbound service formats are `claude -> claude_messages`, `responses -> openai_responses`, `openai -> openai_chat`, and `gemini -> gemini_contents` (`backend-go/internal/passthrough/passthrough.go:72`). Strict body passthrough and raw response passthrough are currently true only when inbound and outbound formats match (`backend-go/internal/passthrough/passthrough.go:91`, `backend-go/internal/passthrough/passthrough.go:100`).

### Body/header/response/SSE/usage contracts

| Area | Current behavior | Target behavior |
|---|---|---|
| Same-format body | Central decision allows strict body only on format match (`backend-go/internal/passthrough/passthrough.go:91`). Messages -> Claude patches top-level `model` only when mapping exists and otherwise keeps body bytes (`backend-go/internal/providers/claude.go:44`). Responses -> Responses patches platform fields and normalizes input before marshal (`backend-go/internal/providers/responses.go:93`). Byte-exact request body is not required where platform patches need JSON rewrite, but semantic passthrough should be explicit. |
| Cross-format body | Cross-format paths use protocol converters or compatibility branches. Examples: Chat -> Claude conversion (`backend-go/internal/handlers/chat/handler.go:289`), Responses -> Claude/OpenAI/Gemini converter factory (`backend-go/internal/providers/responses.go:90`), Gemini -> Claude/OpenAI/Responses converters (`backend-go/internal/handlers/gemini/handler.go:371`). | Keep conversion explicit. | Header order | Most paths use `PrepareUpstreamHeaders` to clone inbound headers, set `Host`, strip sensitive/proxy/hop-by-hop headers, and set `Content-Type` (`backend-go/internal/utils/headers.go:110`, `backend-go/internal/utils/headers.go:127`). This stage and subsequent forwarding builder work should not replace the ccx control plane:

- Scheduler and channel selection stay in `HandleMultiChannelFailover`, which calls `channelScheduler.SelectChannel` and sets trace affinity only after a successful request (`backend-go/internal/handlers/common/multi_channel_failover.go:74`, `backend-go/internal/handlers/common/multi_channel_failover.go:93`).

## Caveats / Not Found

- Chat -> `gemini` and Chat -> `responses` are classified as cross-format by `passthrough.Decide` because the service formats are Gemini Contents and OpenAI Responses, but the current Chat handler sends OpenAI-compatible Chat requests to `/v1/chat/completions` and raw-forwards non-Claude Chat-shaped responses/SSE. This is a compatibility behavior that should be treated carefully in later builder work rather than silently changed in same-format migration.
- Chat -> OpenAI same-format request body is not byte-preserving today because the handler unmarshals and marshals a map, but it generally preserves unknown fields and patches model/platform fields.
- Gemini -> Gemini same-format request body is not byte-preserving today because it marshals a typed `GeminiRequest` and may strip/inject `thoughtSignature`; non-stream response and stream bytes are raw-preserved.
- Responses -> Responses same-format request body is not byte-preserving today because it patches platform fields, normalizes input, and marshals JSON; non-stream and stream responses are raw-preserved while usage/session parsing is side-channel.
- `passthrough.Decide` currently ignores the `apiKey` argument. No evidence was found in the inspected paths that selected key format changes same-format decisions.
- The parent task mentions AxonHub style, but no external AxonHub source or docs were available/needed for this matrix.

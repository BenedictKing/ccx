## 八、流程问题（比单条 bug 更值得修）

1. **PR 没有测试门禁**。`.github/workflows/` 里 5 个工作流只覆盖 release / docker / docs / homebrew / desktop bindings 同步，**没有任何一个在 PR 上跑 `make test` 或前端构建**。结果是 8 个 PR 全部 `checks=0`，只能靠人工判断，队列自然堆积。
2. **issue 无标签无里程碑**。36 条 open issue 零标签，`TODO.md` 只有 1 条，issue 列表和开发清单是两套系统，用户看到的是"没人管"。
3. **对外的路线口径不一致**。维护者已在 #294/#295/#301 答复"3.0 会做"，但 `v3-port-inventory.md` 把自动路由/自动降级列为暂缓。发布前需要统一说法，避免 3.0 交付时出现预期落差。

# 中转站账号到 Agent 的接入实施计划

## 用户目标与边界

- 用户提供站点凭据，选择 Agent、主模型和显式备用模型；系统维护分组、Key、倍率和连接配置。
- 保留六协议独立配置；用户选模，系统仅按可用性、协议和用户价格约束执行确定性规则。
- 沿用现有 Key/BaseURL/渠道重试和流式提交边界，不引入 ChannelsV3、质量评分或竞速。
- 不操作 3688 运行实例；验收只使用隔离配置和本地假站点。

## 阶段与依赖

1. 稳定身份与接入可靠性：账号凭据更新保留托管记录；渠道按账号/协议/分组稳定绑定，兼容旧指纹；并发更新原子化；Responses 原生路径与验收一致。
2. 分组倍率与持续维护：接入写入真实倍率和来源；渠道级倍率上限进入 Key 调度；同步远端 Key 状态、分组和倍率；临时管理面错误保留最近可信值。
3. 已有 Key 与 Agent 接入：账号已有 Key 复用、独立推理 Key 导入；Agent 模板生成协议和显式映射；模型先选，分组按目标模型筛选；错误在当前步骤可见。
4. Web/Desktop 闭环：两端接入同一后端契约；提供连接信息、账号继续配置和倍率编辑；Desktop 复用现有 Agent 配置预览与应用。
5. sub2api 管理适配：先验证目标版本公开接口，支持的能力接入账号流程；接口不兼容时保留已有 Key 导入，不假装已托管。
6. 显式降级与诊断：主模型优先，备用模型按用户顺序；统一总时限/次数；保留上下文、视觉与工具约束；展示失败原因和当前状态。

阶段 2/3 依赖阶段 1；阶段 4 复用阶段 3 契约；阶段 5 复用接入能力边界；阶段 6 复用已有调度与故障分类。

## 兼容与回滚

- 新字段均可选；无托管元数据的手工渠道保持原行为，未知倍率不自动当作零成本。
- 已有账号 UID 保留；换令牌使用明确账号身份，重复接入只更新凭据，不清空 Key/证据。
- 旧托管渠道仅在指纹能证明归属时接管；同站点多账号和用户改名不得串绑。
- 远端创建和本地持久化记录结果；失败只补偿本次新建且明确归属的资源。
- 不自动复活人工删除/排除对象；管理端查询失败不等于推理不可用。
- 每阶段独立提交，可通过恢复前一版本与对应配置备份回退；不改现有正式数据。

## 验收

- 后端：假站点契约、账号重复接入/凭据轮换、同站点多账号、渠道改名、保存重启、并发更新、倍率越限及恢复、故障重试边界。
- 接入：new-api 账号和已有 Key 均可完成；sub2api 按已验证能力执行；验收请求走实际配置路径并验证响应语义。
- 前端：依赖 preflight、Web/Desktop 类型检查/构建、相关行为测试、改动文件 lint，以及真实浏览器接入检查。
- 全栈：根目录构建、后端全量测试；已有全仓 lint 错误单独记录。
- 每阶段记录实际完成范围和证据，未验证能力不标记完成。

## 执行记录

- 初始检查：工作区已有两份桌面图标修改、`.workbuddy/` 和旧巡检计划，均不属于本任务。
- 基线：`d365818d`；基于 v2.9.37 的独立分支，与 main 已分叉，不能 ff-only 合并主线。
- 阶段 1：已实现账号凭据增量更新、锁内 Patch、账号/分组归属、旧指纹兼容和并发编辑冲突保护。Responses 接入使用原生端点，验收复用 Responses 请求转换器。
- 阶段 2：已实现倍率来源/时间、`null`/零上限、六协议准入、远端停用/过期/额度/分组变动同步；同步失败保留可信值并展示错误。按 Token ID 对账，分页不完整时拒绝判定删除。
- 阶段 3：已实现已有远端 Key 选择、推理 Key 单独导入、Agent 默认别名及精确覆盖、模型先选再筛组。无模型目录时允许人工输入；接入计划随账号保存。
- 阶段 4：Web/Desktop 都接入 `/api/siteaccess/*`；Desktop 补上倍率编辑与接入后的 Agent 配置预览入口，复用已有确认/恢复流程。
- 阶段 5：已实现 sub2api Bearer JWT 管理适配，支持用户专属倍率、幂等创建和已有 Key；不代办登录验证码/2FA。契约基于公开源码，未调用用户真实站点。
- 阶段 6：已实现用户指定模型序列、跨渠道共享尝试次数与重试窗口、精确目标过滤；原流式提交边界及上下文/视觉检查继续生效。已有渠道日志记录请求模型和实际目标。
- 可选维护：仅启用 `autoSyncGroups` 后补接新出现且已确认包含目标模型的分组；排除组和已删除的渠道/远端 Key 不会自动复活。

## 实现与验证说明

- 单元/契约覆盖：换令牌不换身份、并发证据不丢失、同站点账号隔离、渠道改名、后台同步不覆盖人工编辑、倍率上限清空/零值/重启、涨价及回落、sub2api 零倍率/重复创建、已有 Key 导入。
- 重试集成测试使用本地 HTTP 上游：模型缺失后使用备用模型；最多 2 次尝试时第三把 Key 不发送；上游已处理完成后不再跨模型重试。
- Web 浏览器：隔离端口 5188/3188 和假站点 3199，完成账号接入、模型选择、倍率筛组、创建 Key、真实请求验收。
- 运行时：实际网关收到 `gpt-client` 后按 `gpt-primary → gpt-backup` 顺序发送，返回备用模型内容；远端倍率从 0.5 变为 2.5 再回到 0.5，均同步到本地。
- Desktop：真实 Vue 接入组件在隔离浏览器宿主中完成同接口接入、计划恢复和配置预览事件；宿主的 Wails 凭据桥接使用本地测试替身，未改写用户 Agent 配置文件。
- 发现并修复：远端空 Key 列表返回 null 导致向导崩溃；未注册复选组件导致开关不显示；旧 watcher 测试非原子计数导致 race；对账测试退出时未等后台协程。
- 配置更新保持 `channelsV3` 拒载保护，本轮不做整份 3.0 数据迁移。
- 重试窗口约束上游尝试和首内容等待，不终止已经交付给客户端的正常长流。明确站点级过载仍遵守渠道冷却，备用模型需要有合格渠道。
- 尚未进行用户真实站点、完整 Wails 原生应用和签名安装包验收；这些不等于已通过生产验证。
- 自动检查：`make build`、后端及 Desktop `go test ./...`、相关五包 `go test -race` 通过；Web 219 项、Desktop 93 项前端测试及两端类型检查/构建通过。定向 ESLint 仅保留已有警告；全仓历史 lint 问题不在本轮扩大修复。

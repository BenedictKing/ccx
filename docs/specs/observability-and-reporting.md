# 可观测性、请求历史与用量报表

> 状态：现行规格
> 代码基线：`53b79829`

## 1. 目标与范围

可观测性回答四类问题：渠道是否健康、一次客户端请求经历了什么、请求模型最终流向哪里、某时间段的用量和估算是多少。

- 六类入口分别维护指标和渠道日志；逻辑请求与上游尝试分开计数，不能将重试当成多个客户端请求。
- 覆盖聚合指标、最近渠道日志、模型去向、长期请求历史、Key 运维、运行诊断和月度 CSV 报表。
- 历史以调用时快照为准，渠道改名、删除、重排和映射热更新不得重写旧记录。
- 观测写入失败不得阻断代理，但覆盖范围、丢弃、未知结果和数据库异常必须可见。

非目标：不记录完整提示词/响应作为观测事实，不推断上游内部重定向，不用最近 50 条内存日志冒充全量统计，不把估算费用当作上游账单。

## 2. 页面与交互契约

- **全局统计**：协议页共享时间范围和刷新状态，展示请求、成功率、延迟、Token、缓存和费用趋势；局部模型去向筛选不得改变原趋势。
- **模型去向**：位于全局统计内，采用“请求模型 → 渠道 → 实际发送模型”三列流向；支持三维筛选、成功请求去向/全部上游尝试、路径下钻和请求详情。窄屏使用路径卡片和全屏详情，不以横向表格替代。
- **渠道日志**：展示生命周期、状态码、来源、BaseURL、脱敏 Key、原模型/实际模型、重试和耗时；Images 额外显示 operation，缓存与 TPS 等字段按实际记录展示。
- **请求历史**：支持状态、搜索、请求模型、渠道、实际模型和 Key 筛选，游标分页；提供 15m/1h/6h/24h/7d/30d/全部保留范围，超出保留期明确拒绝。
- **Key 运维**：渠道菜单按脱敏 Key 展示 15 分钟请求量、成功率、最近失败及操作记录，可携带渠道、Key、attempt ID 跳转请求历史。
- **运行诊断**：顶栏展示版本、持久化配置、保留范围、待写入、丢弃和清理异常；可导出仅含低敏字段的 JSON。
- **报表导出**：全局统计的下载对话框包含月份、全部/单渠道、hour/day 粒度；未来月份禁止，导出期间显示加载，价格仅为估算提示。

加载、空态、筛选无结果、覆盖不足、游标过期、数据库失败和已删除渠道都必须有独立展示，不能一律显示“暂无数据”。

## 3. 请求、尝试与指标口径

| 概念      | 统计契约                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------------ |
| 逻辑请求  | 通过鉴权并进入代理处理的客户端调用，以 `gatewayRequestId` 去重；包含选渠前失败。                       |
| 上游尝试  | 进入实际出站边界的渠道/URL/Key 调用，含连接失败；候选过滤和请求构造失败不伪造尝试。                    |
| 重试/切渠 | 尝试数大于 1 为重试；不同渠道数大于 1 为切渠。同渠换 Key/URL 不误标切渠。                              |
| 终态      | 成功、失败、取消互斥，未结束为进行中；崩溃遗留为未知，HTTP 200 后断流不等于成功。                      |
| 时间      | 请求及全部尝试按逻辑请求接收时间归属；跨窗口重试不拆开同一请求。                                       |
| 模型      | 保存 requested/effective/mapped/sent 四层及有序变换步骤，不从响应模型或当前映射反推历史。              |
| 渠道      | 保存 UID、调用时名称、serviceType 和配置版本；同 URL/Key 的不同渠道不合并，删除后标已删除。            |
| 来源      | 默认业务分布仅 `requestSource=proxy`；能力测试、发现、ping、预热不混入，compact 作为内部辅助调用关联。 |

- “成功请求去向”每个成功请求只归最终成功路径；“全部上游尝试”包含失败、取消和进行中尝试。两个分母和占比不得复用。
- 首字节与首内容是独立样本；首内容只统计已结束且观测到内容的请求，客户端取消和内部忽略重试不计入。P50/P95 使用有界近似，样本少于 5 时提示不足。
- 渠道日志按 metricsKey 最近保留 50 条且为内存态，生命周期含 pending/connecting/streaming/completed/failed/cancelled。
- 模型去向内存窗口最多 50,000 个逻辑请求，固定查询快照额外保留 15 分钟宽限；达到容量或覆盖起点必须显示不完整。

## 4. 历史、诊断与报表运行逻辑

### 存储与查询

- `routing_records_v1` 以逻辑请求 ID 保存请求及全部尝试的原子 JSON 快照；异步写入、关闭排空，启动加载最近窗口并将遗留在途标为未知。
- 模型去向接口为 `/api/{type}/models/routing`、`/requests`、`/requests/{id}`；首屏聚合使用同一快照和 `asOf`，键集游标绑定筛选与窗口。
- 长期历史使用 `/history`，支持独立状态/搜索/Key 过滤。游标 15 分钟过期，改变筛选必须重新查询；410 与空结果区分。
- 请求历史与 Key 操作保留期由 `REQUEST_HISTORY_RETENTION_DAYS` 独立控制，默认 14 天、范围 1–366；聚合指标由 `METRICS_RETENTION_DAYS` 控制。
- 最近失败摘要最多扫描该渠道最近 1000 个保留请求，包含最终成功请求中的失败尝试；达到扫描上限时展示覆盖提示。

### 用量报表

- `GET /api/reports/usage/channels` 只返回报表渠道 ID、名称和协议，不返回凭证或上游地址。
- `GET /api/reports/usage.csv` 需要 SQLite，参数为本地时区、YYYY-MM 月份、all/单渠道及 hour/day；默认 UTC 和 hour，未来月份及非法参数返回 400。
- CSV 带 UTF-8 BOM，包含桶开始时间、协议、渠道、模型、请求/成功/失败、Token、缓存、平均 RPM/TPM、估算 USD 和 attribution。
- 渠道归属按协议+指标身份匹配：唯一匹配为 matched，多渠道共享身份为 shared，无法归属为 unattributed；选择单渠道时不把共享/未知记录强行归入。
- 费用按当前模型/渠道价格配置计算，只作估算。渠道名、serviceType、模型等 CSV 文本防公式注入。

## 5. 持久化、安全与异常边界

- 观测只保存模型、渠道、状态、时间、延迟、用量和必要调度元信息；不保存提示词、响应正文、完整 Key、Authorization 或带查询参数 URL。
- Key 运维使用 SHA-256 Key ID 和脱敏显示，操作记录不保存完整 Key、上游错误正文或操作者身份；单管理密钥模式不能区分人员。
- 所有历史、Key 运维、诊断和报表接口要求管理员认证，并按入口协议隔离，跨协议 request ID 不可读取。
- `/api/diagnostics` 只返回版本、策略、计数和时间等白名单字段，不包含 Key、正文、内部路径或环境变量。
- SQLite 不可用时相关接口明确返回失败或 503，不把查询失败当成空库；指标可降级内存，但导出和长期历史能力随之受限。
- 写入队列丢弃、清理失败、覆盖起点、遗留未知和最近操作时间必须暴露；计数主要从本次启动累计的字段不得包装成永久总量。
- 观测写入不阻断客户端响应，关闭时尽量排空；报表 CSV 流式写失败记录错误，不能继续宣称文件完整。
- 历史数据清理按各自保留期执行，备份和删除 `metrics.db` 时同时考虑聚合指标、请求历史与 Key 操作。

## 6. 验收标准

| 场景                 | 必须结果                                                                     |
| -------------------- | ---------------------------------------------------------------------------- |
| 单请求直接透传       | 1 请求、1 尝试、未命中且模型不变，成功去向计数一致。                         |
| 同渠重试与跨渠道成功 | 请求数不增加，尝试数和切渠标记准确，成功图只归最终成功路径。                 |
| 无候选/构造失败/取消 | 无候选不产生尝试；取消不归成功；失败原因可下钻。                             |
| 渠道与配置变化       | 改名/重排/删除/映射更新后历史仍使用调用时快照，UID 不串。                    |
| 六协议与内部调用     | 协议隔离，能力测试/发现/预热不计默认分布，compact 不重复计入。               |
| 重启与部分写入失败   | 遗留在途标未知，丢弃和覆盖可见，不伪造完整历史。                             |
| 历史筛选与游标       | 状态/搜索/Key 正确，保留期超限拒绝，过期游标返回 410 且可重新查询。          |
| 报表与诊断           | 时区/月/粒度/归属正确，CSV 防公式注入，诊断无敏感字段，DB 失败不显示空成功。 |

统计验收用手工构造的固定请求集核对计数、占比和时间窗口，再与本地假上游实际收到的模型对照；前端覆盖长短名称、空态、窄屏和键盘路径。
